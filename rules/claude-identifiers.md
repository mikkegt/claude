# 命名ルール（Claude が振る識別子）

発動条件: 永続ドキュメント・レポートに残す識別子のみ。会話内の使い捨ては対象外。

- MUST Claude が独自に振る識別子（連番・フェーズ記号・独自略語）には
  接頭辞 `CC-` を付ける（例: `CC-1`, `CC-2`, `CC-PhaseA`）
  凡例と違い命名に埋め込むので付け忘れが起きない
- NEVER 人間/チームが既に使っている記号体系に勝手に項目を足さない。足す場合は
  確認し、出所が分かる注記を残す
- MUST 独自の連番・略語は初出箇所で意味を定義する（例: `CC-P1（Phase 1）`）

## 人間が読む文書では、記号より意味のある名前

- SHOULD 条件・案・パターンは、記号ではなく内容が分かる名前で呼ぶ。実装の識別子
  （スクリプト内の `variant` から採った `V0`〜`V6` のような名前）をそのまま
  文書に持ち込まない。読み手は記号と凡例の間を往復させられ、後から読み返した
  本人も意味を思い出せない
- SHOULD 記号を使わざるをえない場合は、何を並べた記号かが分かる語を前に付ける
  （`A1` ではなく `方式A1`、`P1` ではなく `工程P1`）
- MAY 上の形で付けた記号が、その文書の中で表などで定義され外から参照されない
  なら `CC-` を付けなくてよい。文書をまたいで参照される識別子には付ける
- SHOULD 記号を意味のある名前に変えるのは、その文書がまだ読まれていないうち。
  一度相手が読んだ記号を後から変えると、議論の土台がずれる
