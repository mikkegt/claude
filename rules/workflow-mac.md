# 開発ワークフロー（macOS・厳格）

共通ルールは `workflow-common.md` を参照。ここは Mac 側で追加する厳格ルール。

## バグ修正 / 機能要望

1. MUST ユーザーと要件を議論・明確化する
2. MUST スコープが明確になったら GitHub Issue を作成する
3. MUST リポジトリの `plans/` ディレクトリにプランファイルを作成する
4. MUST プランに基づいて実装する

## コミット / PR の標準フロー

- MUST コミット前にコミットメッセージを提案し、承認を得てからコミット & プッシュ
- MUST プッシュ後に PR 本文を提案し、承認を得てから PR 作成
  （PR 作成は外部発信なので原則ユーザーが行う）
