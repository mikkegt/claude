# プライベート→パブリック持ち込み防止

事故は「プライベートリポで作業中の文脈を持ったまま、パブリックリポへ書き込む」
一点で起きる。公開リポは一度書くと履歴・インデックスに残り、後から消しても辿れる。
この遷移だけ確実に止める。

発動条件: プライベート → パブリックの書き込み
（例: 案件で得た知見を公開ルール・CLAUDE.md に追記する場面）

- MUST 書く内容にプライベート由来の固有情報が紛れていないか見直す:
  案件名・プロダクト名・コード名・リポジトリ名 / 未公開の設計・数値・体制・取引先 /
  個人名（無名化）/ ローカル限定パス / ユーザーの生の指示文（User Prompt）
- MUST 例や背景は固有名詞を伏せて一般化する（「あるプロジェクトで」等）
- MUST 迷ったら本人に確認する
